# Task Management App

A simple and responsive Task Management App built with React.js.  
This application helps users create, manage, update, delete, and track their daily tasks from a clean and easy-to-use interface.

## 🚀 Live Demo

View Live Demo:- https://task-management-app-six-lyart.vercel.app/

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ⏳ Track pending tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📊 View total, completed, and pending tasks
- 📱 Responsive user interface
- 🎨 Clean and simple design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
